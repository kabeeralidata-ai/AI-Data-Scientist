Features excluded, and why

ColumnReason excluded
Order IdIdentifier column (e.g. an ID) — carries no predictive signal.
Order DateRaw date — replaced with derived year / month / day-of-week features instead.
ProfitLeakage. 'profit' is named like a value computed FROM other monetary fields (e.g. profit = revenue - cost), and correlates with the target here (89%) — likely calculated alongside 'sales_amount' from the same transaction rather than known beforehand, which would let the model 'cheat' by learning a near-reconstruction of the target.
Reviewed, not excluded: Unit Price (85.0% correlated) — no evidence these are derived from the target, so they were kept as legitimate predictors, but worth a manual sanity check.
